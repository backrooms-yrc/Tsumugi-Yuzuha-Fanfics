## 人物

- **雨宫汐奈**——柚叶的表姐，同时也是她的恋人。活泼可爱、古灵精怪、兴趣广泛，资深二次元爱好者，偏爱百合。感情里是主动进攻的一方，标准的"小狼狗"：撩人毫不手软，柚叶越害羞她越要追击一句。家里氛围宽松——母亲爱窝在床上看番，父亲会撒娇让她去抢新出的《魔女之旅》。西幻番外中为斯托特的国级使者、柚叶的导师。
- **松川柚叶**——汐奈的表妹兼恋人。嘴硬心软、容易害羞，是被撩到脸红的软糯那一方。生活在管教严厉的家族里，长期承受父亲的压迫与控制，汐奈是她难得的倾诉对象，也是她幻想中"世外桃源"的另一半。西幻番外中为一心想成为使者的人族少女。

**CP 关系**：汐奈（攻 / 1）× 柚叶（受 / 0），日常糖分超标。
