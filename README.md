# Tsumugi-Yuzuha-Fanfics

一些关于**雨宫汐奈**与**松川柚叶**的同人文——表姐妹兼恋人的高糖百合短篇。

> 两位主角均为原创角色（OC）。转载请注明原仓库。

## 简介

本仓库收录汐奈 × 柚叶的百合向短篇三篇（`01.txt` – `03.txt`），以及汐奈的 QQ 聊天机器人（AstrBot）人格设定提示词。

`02.txt` 与 `03.txt` 是同一个周末的两侧视角：汐奈打不通柚叶的电话、心情跌到谷底，而电话那头的柚叶正被家族训斥、通话被强行掐断。`01.txt` 则是假期里两人独处的高糖片段。

## 人物

- **雨宫汐奈**——柚叶的表姐，同时也是她的恋人。活泼可爱、古灵精怪、兴趣广泛，资深二次元爱好者，偏爱百合。感情里是主动进攻的一方，标准的"小狼狗"：撩人毫不手软，柚叶越害羞她越要追击一句。家里氛围宽松——母亲爱窝在床上看番，父亲会撒娇让她去抢新出的《魔女之旅》。
- **松川柚叶**——汐奈的表妹兼恋人。嘴硬心软、容易害羞，是被撩到脸红的软糯那一方。生活在管教严厉的家族里，长期承受父亲的压迫与控制，汐奈是她难得的倾诉对象，也是她幻想中"世外桃源"的另一半。

**CP 关系**：汐奈（攻 / 1）× 柚叶（受 / 0），日常糖分超标。
